# Portfolio Web

Este es un portafolio personal dinámico y adaptable, creado con tecnologías web modernas. Muestra los proyectos del usuario alojados en GitHub y proporciona información sobre sus habilidades técnicas.

---

### Características

- **Galería de Proyectos Dinámica**: Obtiene y muestra automáticamente los repositorios de un usuario de GitHub. Los proyectos se presentan en un carrusel interactivo.
- **Carrusel de Proyectos**:
    - Muestra los proyectos en diapositivas de tres en tres.
    - Incluye controles de navegación "siguiente" y "anterior".
    - Cuenta con una función de reproducción automática que desplaza los proyectos cada 15 segundos.
    - Los proyectos están ordenados por el número de estrellas, de más a menos populares.
- **Internacionalización (i18n)**: Toda la interfaz de usuario es compatible con inglés y español. Un selector de idioma permite a los usuarios cambiar el idioma en tiempo real.
- **Diseño Responsivo**: El diseño es totalmente responsivo y se adapta a diferentes tamaños de pantalla, desde dispositivos móviles hasta ordenadores de escritorio.

### Tecnologías Utilizadas

- **Framework**: [Next.js](https://nextjs.org/) (con App Router)
- **Lenguaje**: [TypeScript](https://www.typescriptlang.org/)
- **Estilos**: [Tailwind CSS](https://tailwindcss.com/)
- **Componentes de UI**: [ShadCN UI](https://ui.shadcn.com/)
- **Iconos**: [Lucide React](https://lucide.dev/guide/react)
- **Internacionalización**: Implementada con React Context y archivos JSON.
